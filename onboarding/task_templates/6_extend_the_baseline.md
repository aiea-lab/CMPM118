# Task 6: Extend the Baseline

## Objective

Implement one controlled change that tests a clear hypothesis.

## Tasks

- [ ] State a falsifiable hypothesis and choose one independent variable.
- [ ] Agree on the smallest useful implementation with the project lead.
- [ ] Add the change behind a configuration option or separate script.
- [ ] Add a smoke test or other reproducible check.
- [ ] Run the original baseline and the extension under matched conditions.

## Deliverable

Submit the hypothesis, implementation summary, initial comparison, limitations, and links to tested commits.
