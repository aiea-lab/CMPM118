# Onboarding "Skill Development" Tasks
For the AIEA Auditor program (CMPM 118) you will do 10 onboarding
tasks over the 10 week quarter.  (Note: [the first
task](1_onboarding.md) and the [last task](10_offboarding.md) are the same for each project.

After task 1, you will choose your project, which have tasks 2-9
defined in the respective folders.  The current projects are:
- [AI ethics](proj_ai_ethics/)
- [NeuroSymbolic AI](proj_llm_logic_nesy/)
- [Neural Explanations for LLMs
(language)](proj_neural_explanations_llms)
- [Neural Explanations for Vision](proj_neural_explanations_vision/)
- [Robustifying Autonomous Vehicles](proj_robustifying_avs)
- [Self-Explaining Neural Networks](proj_self_explaining_neural_networks)

To work on these tasks, you can clone the full repository.
