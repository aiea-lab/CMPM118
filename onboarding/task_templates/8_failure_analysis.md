# Task 8: Failure Analysis

## Objective

Turn aggregate results into a structured account of where and why the system fails.

## Tasks

- [ ] Define a sampling rule for at least `[NUMBER]` failures.
- [ ] Create a small taxonomy of failure modes without using test labels improperly.
- [ ] Annotate the sample and report category counts.
- [ ] Compare at least two representative examples per major category.
- [ ] Test one plausible explanation for the most important failure mode.

## Deliverable

Submit the taxonomy, annotated sample, category summary, representative examples, tested explanation, and proposed mitigation. Clearly separate observations from hypotheses.
