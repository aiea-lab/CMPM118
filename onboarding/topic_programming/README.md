# Programming

Learn the Python and research programming skills used throughout the lab.

## Tasks

Complete the shared [Task 1](../1_onboarding.md), then [Task 3: Python and Research Programming Basics](3_python_crash_course.ipynb). The tutorial includes worked examples, predictions, and exercises using only the Python standard library. After a short warm-up, build a validated CSV pipeline, compare matched experimental runs, debug shared mutable state, and generate a reproducible JSON report. Submit the completed notebook to Canvas.

Continue with [Task 4: Unit Tests and Continuous Integration](4_testing_and_ci.md), using pytest and GitHub Actions to test your Task 3 analysis pipeline. Tasks 2 and 5–9 have not yet been added. Use the shared [offboarding checklist](../10_offboarding.md) at the end of the quarter.
