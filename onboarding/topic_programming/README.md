# Programming

Learn to turn a research question into reliable, reproducible Python tools. You will validate experimental data, compare results, write unit and integration tests, and automate checks with continuous integration. By the end of the available tutorials, you will have a tested command-line analysis pipeline that another researcher can run.

## What you will learn

- Parse and validate experiment records while preserving an audit trail.
- Compare matched experimental runs and interpret limitations.
- Write unit and integration tests, run CI, and build a usable command-line interface.

## Getting started

Read the shared [Task 1: Lab Onboarding](../1_onboarding.md) and the [onboarding overview](../README.md). Start with basic Python familiarity and the shared Git/repository practice in Task 1. Task 3 uses only the Python standard library. Task 4 introduces pytest and GitHub Actions; Task 5 reuses that environment. Record Python and dependency versions in your task repository.
