# Vision

## Tasks

Complete the shared [Task 1: Lab Onboarding](../1_onboarding.md), then the available Vision tasks in order:

- [Task 3: Math Review and PyTorch Basics](3_pytorch_crash_course.ipynb)
- [Task 4: Training Neural Networks — Instructions](4_training_neural_networks/Task_Instructions.pdf)
- [Task 4 starter code](4_training_neural_networks/)

Follow the PDF for Task 4 setup, exercises, and submission requirements. Tasks 3 and 4 are imported from the main branch. Additional Vision tasks have not yet been added to this folder. Complete the shared [offboarding checklist](../10_offboarding.md) at the end of the quarter.
