# Symbolic + Logic + Human-centered

Learn to represent knowledge explicitly and use logical rules to derive and explain conclusions. You will build and test Prolog knowledge bases, implement recursive reasoning, and examine how missing or incorrect records affect decisions. The project connects these foundations to faithful reasoning with language models and to explanations that people can inspect and contest.

- **Lead:** Leilani H. Gilpin
- **Project collaborators listed on the website:** Olivia Peiyu Wang and Priyesh Vakharia
- **Project page:** [Faithful Reasoning](https://aiea-lab.github.io/project/faithfulreasoning/)
- **Reading list:** [Reading list](#reading-list)
- **Published papers:** [Published papers](#published-papers)

## What you will learn

- Translate claims into facts and rules and distinguish inference from truth.
- Build, query, explain, and test a Prolog knowledge base.
- Use recursive reasoning and examine the human consequences of missing or incorrect records.

## Getting started

Read the shared [Task 1: Lab Onboarding](../1_onboarding.md) and the [onboarding overview](../README.md). Task 3 uses only the Python standard library. Tasks 4–5 introduce SWI-Prolog and PlUnit, with a documented browser fallback. These foundational tasks do not require an LLM or paid API. Later tasks introduce additional logic and language-model frameworks; follow their setup instructions separately.

## Deliverables

Submit the artifacts requested in each assignment to its Canvas deliverable. For code-based work, include setup and reproduction commands, versions, configurations, and output evidence. For reading-based work, include passage references and distinguish the authors' claims from your interpretation. Follow each task's specific format, evaluation criteria, and fallback instructions.
