# Task 7: Evaluate the Extension

## Objective

Determine whether the Task 6 change improves the intended behavior without hiding important tradeoffs.

## Tasks

- [ ] Select primary and secondary metrics before running the experiment.
- [ ] Use fixed splits, matched budgets, and multiple seeds where appropriate.
- [ ] Compare the baseline and extension quantitatively.
- [ ] Check runtime, memory, or cost as relevant.
- [ ] Save configurations and raw results in a reproducible form.

## Deliverable

Submit a concise results report with plots or tables, uncertainty or run-to-run variation, an interpretation tied to the hypothesis, and links to artifacts and commits.
