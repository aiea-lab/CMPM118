# Robustifying Autonomous Vehicles

This track uses simulation, reinforcement learning, and falsification to identify and reduce autonomous-vehicle failures.

- **Lead:** Leilani H. Gilpin
- **Project page:** [Robust Autonomous Vehicles](https://aiea-lab.github.io/project/robustavs/)
- **Reading list:** [Reading list](#reading-list)
- **Published papers:** [Published papers](#published-papers)

## Tasks

Complete the shared [Task 1](../1_onboarding.md), Tasks 2–9 in this folder, and the shared [Task 10](../10_offboarding.md), in numerical order.
