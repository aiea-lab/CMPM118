# Task 3: Project Onboarding

## Objective

Understand the project’s research question, people, code, data, and current baseline well enough to begin contributing.

## Tasks

- [ ] Read the project README, reading list, and contribution instructions.
- [ ] Meet or check in with `[PROJECT LEAD]` and join `[PROJECT CHANNEL]`.
- [ ] Read the documentation for `[PROJECT REPOSITORY]`.
- [ ] Clone the repository and create a reproducible environment.
- [ ] Identify the main dataset, model or method, evaluation metric, and known limitation.
- [ ] Run the smallest documented example or test.
- [ ] Record setup problems and their solutions.

## Deliverable

Submit a one-page project map containing the research question, key people and resources, a diagram or concise description of the baseline pipeline, proof that the example ran, and two questions you would investigate next.
