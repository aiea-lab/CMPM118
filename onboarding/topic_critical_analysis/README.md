# Critical Analysis (Critical theory)

Learn to analyze how power, history, and institutional choices shape AI research and its consequences. You will practice close reading, apply feminist and decolonial perspectives carefully, and critique dataset categories, documentation, and claims about fairness. The introductory sequence emphasizes evidence-based written analysis and prepares you to examine the assumptions behind later AI ethics evaluations.

## What you will learn

- Read and compare arguments about decolonization, power, intersectionality, and situated knowledge.
- Analyze dataset categories, institutional assumptions, and documentation.
- Distinguish textual evidence, hypotheses, and observed results when critiquing technology.

## Getting started

Read the shared [Task 1: Lab Onboarding](../1_onboarding.md) and the [onboarding overview](../README.md).
