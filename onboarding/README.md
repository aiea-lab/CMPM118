# Onboarding Skill-Development Tasks

For the AIEA Auditor program (CMPM 118), you will complete ten onboarding tasks over the ten-week quarter. Tasks are organized by topic in folders prefixed with `topic_`:

- [RL and Reasoning + Agentic](topic_rl_reasoning_agentic/)
- [Vision](topic_vision/)
- [NLP](topic_nlp/)
- [Symbolic + Logic + Human-centered](topic_symbolic_logic_human_centered/)
- [Programming](topic_programming/)
- [Critical Analysis (Critical theory)](topic_critical_analysis/)

Complete the shared [Task 1](1_onboarding.md), then follow the numbered tasks in your chosen topic’s sequence. The existing sequences retain Tasks 2–9 and the shared [Task 10](10_offboarding.md). Vision offers two sequences; Programming is reserved for a future sequence.

To create or revise a topic sequence, use the [task-authoring guide and templates](task_templates/). The revised general sequence is: onboarding, Nautilus, math basics, framework basics, topic basics 1, topic basics 2, advanced usage 1, advanced usage 2, paper reading, and interview or additional topics. In revised sequences, [offboarding](10_offboarding.md) is a separate end-of-quarter checklist. Follow the existing numbered tasks until your topic’s sequence is revised.

The previous project-based organization is preserved on the `project-organization-backup` branch.

To work on these tasks, clone the full repository.
