# Task 9: Propose a Research Direction

## Objective

Synthesize the preceding work into a scoped, testable next step for the project.

## Tasks

- [ ] Identify one unresolved problem supported by Tasks 4–8.
- [ ] Write a research question and falsifiable hypothesis.
- [ ] Specify the baseline, intervention, data, metrics, and ablations.
- [ ] Identify risks, ethical considerations, compute needs, and fallback plans.
- [ ] Create a two-to-four-week implementation and evaluation schedule.
- [ ] Review the proposal with the project lead.

## Deliverable

Submit a two-page proposal and a short presentation. Include the motivation, related evidence, experiment design, expected outcomes, threats to validity, resource estimate, and definition of success.
