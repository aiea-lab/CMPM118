# Onboarding Skill-Development Tasks

For the AIEA Auditor program (CMPM 118), you will complete ten onboarding tasks over the ten-week quarter. [Task 1](1_onboarding.md), Task 2 (Nautilus), and [Task 10](10_offboarding.md) are the same for every project.

After Task 1, choose a project and complete Tasks 2–9 in its folder. The current projects are:
- [AI ethics](proj_ai_ethics/)
- [NeuroSymbolic AI](proj_llm_logic_nesy/)
- [Neural Explanations for LLMs
(language)](proj_neural_explanations_llms)
- [Neural Explanations for Vision](proj_neural_explanations_llms/neural_explanations_vision/)
- [Robustifying Autonomous Vehicles](proj_robustifying_avs/)
- [Self-Explaining Neural Networks](proj_self_explaining_neural_networks)

To create or revise a track, use the [task-authoring guide and templates](task_templates/).

To work on these tasks, clone the full repository.
